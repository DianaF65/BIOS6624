### Notes on model performance measures
FOR X1-X5:
- True Positve Rate = Proportion of times that X1-X5 are selected
  - TPR = mean(X1–X5 selected)
- Type II Error - Proportion of times that X1 - X5 are NOT selected
  - FTR H0 given the H0 is false
  - Type II error = 1 - TPR
FOR X6-X20:
- False Positive Rate - Proportion of times that X6-X20 are selected
  - FPR = mean(X6–X20 selected)
- Type I Error - Proportion of times that X6-X20 are selected
  -- Here, FPR = Type I Error
  -- False positive rate is model-selection language:
    - How often did the method incorrectly include a noise variable?
  -- Type I error is hypothesis-testing language:
    - How often did the method reject/include a variable when its true coefficient
    was actually 0?
    
The FPR and TPR tell us how good the model is at selecting variables
The Type I and Type II error tell us how often we are making statistical mistakes

  1. model_var_performance()
